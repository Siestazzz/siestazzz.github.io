# 原 App 风格交互 mock

本轮仅实现用户 1/2/3 图中的标注；保留旧归档、标签、分类、关于入口，不新增专题、收藏等功能。

## 路径

- `/`：图 1 大厅。文章数是真实 Hexo 文章数量；阅读量为本机演示计数。友链进入 `/friends/`；右下全部文章进入 `/live/`。
- `/live/`：图 2 入口。镜音连静态立绘、可点击切换短句的对话框；阅读文章进入 `/search/`。其他原游戏卡片只是装饰，无点击事件。
- `/search/`：图 3 选文。左侧使用 Hexo 分类作为大类；输入框匹配标签、标题、正文；列表选中后右侧显示封面、标题、日期、标签、摘要。开始阅读进入原文章 URL。随机一篇从当前筛选结果选另一篇并更新预览，再点击阅读；不足两篇时禁用。
- 文章 URL：简单正文 mock，保留现有 Markdown 内容。返回列表恢复查询、分类和选中文章。
- `/friends/`：使用用户提供的七个博客作为演示链接，明确不是已互换友链；外部新窗口打开。

没有配置 cover 的文章按顺序使用三张原游戏背景作为演示封面；可以在文章 front matter 中填写 `cover`。没有改变原来的文章内容。

## 原素材与动态效果

`source/game-assets/provenance.json` 记录从 `com.sega.pjsekai` 6.8.1 导出的文件和 path_id。包括原版卡片底图、团体图标、按钮、背景点阵、水晶、好友和随机图标。运行 `pjskapk/export_blog_assets.py` 可重新导出。

镜音连立绘来自官方页面 https://pjsekai.sega.jp/character/virtualsinger/len/index.html?year=now ，图片为 https://pjsekai.sega.jp/assets/data/webp/character/virtualsinger/len/now/img.png.webp 。为静态官网立绘，不是截图中的 Live2D 姿态；本版轻微摆动仅是 CSS 近似。

原包内菜单动画片段约 167ms、详情滑入 250ms、手机展开 300ms，网页参考这些时长实现过渡；并非已还原所有绑定或精确 easing。开启系统减少动态效果后取消动画。

## 数据边界

阅读量保存在当前浏览器 `localStorage` 的 `sekai-demo-views`，每次加载正文加一；不是全站 PV、不是跨设备统计。失败或禁用存储不会阻止阅读。链接与文章仍为 Hexo 静态页面，菜单和筛选由浏览器 JS 驱动。
