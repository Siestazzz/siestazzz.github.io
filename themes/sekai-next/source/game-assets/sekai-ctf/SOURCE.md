# SekaiCTF menu reference

Source: https://2026.ctf.sekai.team/ — retrieved 2026-09-07 at the user's explicit request to reuse its menu design.

SVG files are unmodified responses from /assets/icon-challenges.svg, icon-scoreboard.svg, ghost-challenges.svg and ghost-scoreboard.svg. They are reference-site assets, not extracted from the local APK. Ownership remains with the original authors; no redistribution license has been verified. Currently used only in this local, unpublished prototype.

Card colors, corner geometry, typography hierarchy and hover/press styles follow /_app/immutable/assets/4.BIFTLEWm.css. Blog text/routes and inactive SOLO LIVE are retained. Dimensions are expressed in phone-container units to preserve relative positioning in this existing page, rather than importing the CTF application's global stylesheet. Chinese labels retain the unified Chinese fallback because Rodin lacks several required simplified glyphs.
